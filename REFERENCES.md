- [Nim Tutorial (Part 2)](https://nim-lang.org/docs/tut2.html) — advanced topics

## Books

- *Nim in Action* by Dominik Picheta (Manning, 2017) — practical guide to Nim
- *Mastering Nim* by Andreas Rumpf (creator of Nim) — deep dive into the language
- *Computer Programming with the Nim Language* by Stefan Salewski — free ebook

## Tools

- [choosenim](https://github.com/nim-lang/nimble) — version manager (installs Nim 2.2.6)
- [Nimble](https://github.com/nim-lang/nimble) — package manager (`nimble install <pkg>`)
